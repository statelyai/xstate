# Migrating from XState v5 to v6

The full migration guide lives in the published documentation:

- [Migrate from XState v5 to v6](docs/xstate-v5-to-v6.md)

It covers every API change by area — inline transition functions and `enq`, guards, schemas, `setup()`, actor logic creators, new v6 features (choice states, route states, state input, timeouts, `actor.trigger`, `actor.select`, the actor registry, serialization), removed exports and packages, persistence, and framework bindings — with before-and-after examples and a migration checklist.
